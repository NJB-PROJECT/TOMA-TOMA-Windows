# Lyrivane

Selected family: **Lyrivane Desktop** (Windows), **Lyrivane Mobile** (proposed Android name).
Alternative names: VerseDock, Nadivra. Creative naming proposals, not trademark clearance.

Ink #0B1016, mint #78EBCB, highlight #A5FFE5, slate #91A6B8.
The ribbon L and flowing strokes represent listening and lyrics. Created with built-in ImageGen, transparent output. PNG master: `src/Assets/Lyrivane.png`; ICO conversion: `src/Assets/Lyrivane.ico`.

## Generation prompt
Create a premium app icon for Lyrivane, a sophisticated live music lyrics desktop application. Icon only, no lettering or wordmark. A striking original continuous folded ribbon forming an abstract capital L combined with three flowing lyric/sound strokes, sculptural but clean flat geometry, luminous mint and cool cyan gradient, very subtle depth. Centered within a dark ink rounded square app tile, ample safe margins, extremely legible at 32 pixels, polished professional software branding, no headphones, no generic music note, no mockup, no shadows outside tile. Transparent background outside the rounded square tile. Square composition.

Historical repository slug, data folder, namespace and MSI UpgradeCode are retained for compatibility. Android code is unchanged in this release.
